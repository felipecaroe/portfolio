What changed

One palette and navigation

All pages load the base styles first and the washed-blue theme last. The header, logo, navigation and footer come from shared partials. Product colours remain in the work itself.

Covers and hover

The Web app camera is inside the tablet. Complete devices move on hover, keeping screens inside their shells. Native phones are sized using the visible phone bounds. Home and Work use one cover library.

Real ENEM screens

Reconstructed SVGs are archived. Six study states use 1170 × 2532 captures from the real staging app, with the outer web toolbar and bottom navigation omitted as requested. Source captures and provenance are retained.

Mobile, captions and controls

The old cover height cap no longer lets phones overlap headings. Captions are centred with the number in the text. Action arrows are SVGs. New Chat images open with the keyboard.

A clear source for future work

The builder now uses current templates. CSS, JavaScript and media versions come from their contents, including cover images that otherwise remained cached after an update. Every build checks links, assets, page structure, shared chrome and stylesheet order.
