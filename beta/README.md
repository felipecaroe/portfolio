# Felipe Amorim · Freelance design site

Unlinked beta copy of Felipe's freelance website, staged in its own `beta/` folder in the public portfolio repository for review. No navigation or homepage links point here. The pages carry `noindex` metadata. The existing portfolio remains unchanged.

The site is static HTML generated from `scripts/build_site.py`, with shared styles in `assets/site.css` and browser behaviour in `assets/site.js`. Existing project imagery, the detailed résumé and the legacy Impulse case are retained.

## Build and preview

From this directory, run:

```sh
python3 scripts/build_site.py
python3 -m http.server 8765
```

Open `http://localhost:8765/`. Copy changes belong in the generator when a page is generated by the script. The résumé and legacy case remain independently maintained.

## GitHub review

GitHub's file browser shows the source files rather than rendering this site. The live path `https://felipecaroe.github.io/portfolio/beta/` becomes available only if this folder is merged into the portfolio's published `main` branch. Keep it unmerged until Felipe approves the visual result.
