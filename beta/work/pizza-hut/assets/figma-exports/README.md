# Pizza Hut Figma exports

The `pizza-hut-node-*.png` files preserve the original supplied Figma frames. Five selected phone-view derivatives appear in `../screens/`, normalised to the same 375 × 812 viewport and 2× display dimensions: menu, basket, delivery home, product configuration and payment. The post-visit feedback screen is intentionally excluded from the case; its original source export stays here for reference.

`pizza-hut-design-system-overview.png` is the exported component overview. Its full-board scale and density make it unsuitable as a case-page mockup without a separate editorial treatment.
